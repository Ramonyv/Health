# HealthTrack

Interactive portfolio demo built with React, TypeScript, Vite, Tailwind CSS, Motion, and Lucide. Based on the supplied Figma frames and original anatomy/organ illustrations.

## Run

```sh
npm install
npm run dev
```

`npm run build` checks TypeScript and produces `dist/`.

Explore all 17 organs by wheel, horizontal trackpad, mouse drag, touch swipe, or arrow controls. Select a card to open the assistant. The three controls below the body switch anatomy views. Escape closes the assistant. Chat is predefined demo content; nothing is stored or sent to a medical service. The other navigation labels are intentionally outside the two-state demo scope.

Browser QA could not be performed because the browser access host was unavailable. Production compilation and local asset checks passed.
